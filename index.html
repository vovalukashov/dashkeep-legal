DashKeep for Jira

Dashboard notes and counts that stay.

Two Jira Cloud gadgets: a note, and a JQL work-item count. Built on Atlassian Forge.

Privacy Support Terms

What it is

  • Note — a dashboard message that survives reload and wallboard.
  • Count — how many work items match a JQL query; click opens the list.

Install

Install from the Atlassian Marketplace listing for DashKeep for Jira. Billing is through Atlassian.
