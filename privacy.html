Privacy policy

Last updated: 2026-09-04 · Contact: support@vovaluka.com

DashKeep is a Jira Cloud app (Atlassian Forge). It is provided by Vladimir Lukashov (individual).

What the app does

DashKeep adds two Jira dashboard gadgets: a note, and a count of Jira work items matching a JQL query you configure.

Data we access

  • Gadget configuration (note text, JQL, optional caption, refresh interval) is stored by Jira as dashboard gadget configuration. We do not copy it to our own servers.
  • Work item counts are requested from Jira as the user who is viewing the dashboard (read:jira-work). We receive a number, not issue summaries, for the count display. Clicking through opens Jira’s own issue navigator.

Data we do not collect

  • We do not have a separate database.
  • We do not sell data.
  • We do not use the note or JQL for advertising.
  • We do not require an account on a third-party site.
  • We do not send End-User Data to vendor-owned servers or third-party subprocessors.

Where data lives

Configuration and Jira API responses stay in Atlassian Cloud (Forge / Jira). The app is designed to run on Atlassian infrastructure without calling vendor-owned backends. In-scope data therefore follows Atlassian data residency for Jira Cloud / Forge.

Logs

We do not write End-User Data (note text, JQL, issue contents) to our own logs. Forge platform logs are processed by Atlassian.

After uninstall

When the app is uninstalled, gadget configuration remains only as Jira dashboard gadget storage on that site, under the site admin’s control. We retain no copy.
